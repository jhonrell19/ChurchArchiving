# Staging evaluation

Keep credential values in their service environment. Use fictional records and PayMongo test mode for evaluation.

| Flow | Configuration and acceptance check |
| --- | --- |
| Admin document view | Open Main Admin → Digital Church Archives and preview a reviewed scan. Only a PDF should appear inside the document preview. Open Certificate reports and return to the dashboard. |
| Twilio SMS | On the Next web service set PHONE_OTP_PROVIDER=twilio, TWILIO_ACCOUNT_SID, TWILIO_AUTH_TOKEN, PHONE_OTP_PEPPER (at least 32 characters), and TWILIO_MESSAGING_SERVICE_SID or TWILIO_FROM_NUMBER. Use a sender authorized for the destination. Sign in as an email-verified test parishioner with a saved Philippine mobile number. Request one code and enter it. Carrier lookup is separately configured. |
| Cloud archive | On Flask configure a private Supabase bucket and the settings in EVALUATOR-ROLLOUT.md, including PARISH_PRIVATE_UPLOADS and the existing upload index/quota migrations. Upload a fictional scan, review OCR, then save. Verify both original and filled PDF after clearing the test instance's local cache or using another instance. |
| Existing scans | On the host with the original upload disk and private database connection, run python church_backend/sync_archive_storage.py for inventory, then add --apply to copy available files. Reruns skip indexed paths. Missing local files need a backup. No file is removed by the copy. |
| QR Ph payment | Set PAYMONGO_MODE=test on both services. Configure PAYMONGO_SECRET_KEY (test key), PAYMONGO_METHODS=qrph and APP_BASE_URL on Flask. Configure the matching PAYMONGO_WEBHOOK_SECRET on Next, with FLASK_API_URL and its shared FLASK_INTERNAL_KEY. Register https://ifimarag.onrender.com/api/paymongo/webhook for checkout_session.payment.paid in the test merchant account. Open an approved payable request, close and resume the same unpaid checkout, then complete a provider test and check the ledger. A return to the dashboard alone cannot confirm payment. |
| Mass transcription | On a Windows parish PC install Python 3.11 with Tk. Once online run py -3.11 -m pip install faster-whisper==1.2.1 av==14.2.0 and transcribe one short recording to cache the base model. In Main Admin → Mass Recordings → Prepare transcript, download the assistant. Run py -3.11 mass_transcription_assistant.py from its folder, pick audio/video and a new JSON filename. After setup, transcription runs offline. When reconnected, import the JSON, review the complete transcript and opening-sentence summary, save and reopen the Mass. |
