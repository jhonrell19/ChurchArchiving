# Older Parishioner Usability Test — Observer Script

**Participant:** one consenting adult parishioner (preferably older than the typical app user). Avoid recording identifying details. **Device:** familiar Android or iPhone, or a laptop in responsive mobile width. **Observer:** a person other than the participant, who does not guide clicks.

## Opening instruction (read once)

> "This is a test of the parish website, not a test of you. Please use the site as you normally would. Tell us what is confusing. I will not tell you where to click. You may stop at any time. We will use only fictional accounts and records."

## Task protocol

| Task | Starting state | Instruction read aloud | Success criterion | Observe without coaching |
|---|---|---|---|---|
| Find registration | Signed-out homepage | "Find where you would register as a new parishioner." | Finds Register link/button within 60 seconds without hints | Wrong clicks, reading difficulty, zoom needs |
| Find a Mass / event | Signed-out homepage | "Find the parish calendar and check the notice for this date." (use a preselected fictional published date) | Opens selected date and reads event date/end date within 90 seconds | Discovers calendar, notices dot, left/right relation |
| Check request status | Signed into **synthetic approved** account with a fictional Pending request | "Check whether your certificate request has been approved." | Opens requests and correctly reads Pending / Approved within 90 seconds | Navigation confusion, labels, scrolling, feedback |
| Sign out safely | Synthetic account | "Sign out when finished." | Finds sign out, confirms session ends; Back does not re-enter protected screen | Mis-taps, missing confirmation |

- Suggested UI fix and screenshot (synthetic-only): __________

## Scoring and follow-up

Pass a task only when completed independently within the time above. No coaching: the observer may repeat the instruction verbatim but never point to controls. Record failures even if completed after additional guidance. Target at least 3 participants, ≥80% independent completion per task, and no blocking accessibility errors before claiming older-adult usability. These are capstone test acceptance criteria, not verified user performance.

Never ask real parishioners to upload real IDs or make actual payments during a usability trial.
